# Synthetic Payment Dataset Schema

## Dataset

- File: `data/processed/transactions_v1.parquet`
- Rows: 100,000
- Version: v1
- Generation seed: 42
- Time period: 2024-01-01 to 2025-12-31
- Dataset type: Synthetic

## Columns

| Column | Type | Description |
|---|---|---|
| transaction_id | string | Unique transaction identifier |
| timestamp | datetime | Transaction timestamp |
| user_id | string | Synthetic user identifier |
| merchant_id | string | Synthetic merchant identifier |
| amount | float | Transaction amount |
| merchant_category | string | Merchant business category |
| payment_method | string | Selected payment method |
| user_segment | string | Synthetic user segment |
| device_type | string | Device used for the transaction |
| network_quality | string | Simulated network quality |
| hour_of_day | integer | Hour extracted from timestamp |
| day_of_week | integer | Day of week extracted from timestamp |
| retry_count | integer | Number of previous retries |
| transaction_velocity | integer | Simulated recent transaction activity |
| user_method_success_rate | float | Historical synthetic success rate for the user's payment method |
| merchant_method_success_rate | float | Historical synthetic success rate for the merchant/payment-method combination |
| failure_probability | float | Synthetic ground-truth probability of payment failure |
| payment_success | integer | Simulated payment outcome: 1 = success, 0 = failure |

## Payment Methods

- UPI
- Credit Card
- Debit Card
- Net Banking
- Wallet

## Ground Truth

The `failure_probability` column is generated by the synthetic payment failure mechanism.

The actual `payment_success` outcome is then sampled probabilistically from that failure probability.

Therefore:

- `failure_probability` is not the ML model prediction.
- `payment_success` is the ground-truth target.
- The ML model will later learn to predict the target using transaction features.
- The ground-truth mechanism must remain separate from the ML prediction pipeline.

## Important Assumption

This dataset represents a simulated payment environment.

It does not contain real financial credentials, real card numbers, real UPI credentials, bank credentials, OTPs, or real payment transactions.
